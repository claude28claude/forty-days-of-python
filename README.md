# Forty Days of Python

A free Python course for complete beginners: 40 short daily lessons, then 90 more days going further (130 days in all): a capstone program, then the tools professionals use (databases, proper tests, command-line tools), ending with a tested final project and a grand final exam.

**Start learning:** https://claude28claude.github.io/forty-days-of-python/

- Real Python runs right in your browser. Nothing to install.
- Every lesson has examples you can run, a step-through simulation that shows what Python does with each line, quick questions, and exercises that are marked automatically.
- Your progress is saved in your own browser. After two visits with internet, the course also works offline.
- Works on a laptop or a phone.
